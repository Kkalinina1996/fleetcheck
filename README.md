# FleetCheck 🚗

FleetCheck is a full-stack web application for vehicle inspections and fleet management.

I built this project independently as a practical portfolio project after completing my Full-Stack Web Development training.

## Features

- Company and employee authentication
- Role-based access
- Vehicle management
- Digital vehicle inspections
- Vehicle handover and return workflow
- QR-based vehicle access
- Issue reporting
- Responsive interface
- REST API
- Supabase database

## Tech Stack

### Frontend
- React
- JavaScript
- Vite
- React Router
- CSS

### Backend
- Node.js
- Express
- REST API

### Database
- Supabase
- PostgreSQL

### Tools
- Git & GitHub
- VS Code
- Postman
- Linux
- AI-assisted development

## Project

FleetCheck was created to solve a real-world problem: making vehicle inspections and handovers simpler, faster and more structured for companies with multiple vehicles.

The project is still under active development, with new features being added.
